    MySQL Database Fuzzing & Testing 🗄️

    MySQL is one of the most popular open-source relational database management systems. During penetration testing, MySQL databases are often targeted for information gathering, privilege escalation, and data extraction.

    Interactive Connection Parameters

    Enter MySQL connection details:



    Basic MySQL Connection

    Interactive Connection

    Connect to a MySQL database using the command line client:

    mysql -u <username> -h <host> -p <database>

    Mysql Rougue Server attack

    https://github.com/allyshka/Rogue-MySql-Server/tree/master https://medium.com/@AzureNinja/proving-grounds-mantis-d044d68bcf6c#:~:text=So%20the%20vulnerability%20(CVE

    Parameter Breakdown

    • -u: Username for the MySQL connection
    • -h: Host/IP address of the MySQL server
    • -p: Prompt for password (more secure than inline password)
    • database: Target database name (optional)

    One-liner SQL Execution

    SQL Command:

    Execute SQL commands directly from the command line without entering interactive mode:

    mysql -u <username> -p<password> -h <host> <database> -e '<sql-command>;'

    Parameter Breakdown

    • -p<password>: Password directly in command (no space between -p and password)
    • -e: Execute the following SQL command and exit
    • '<sql-command>;': SQL command enclosed in quotes

    Dump Database

    mysqldump -u <username> -p<password> -h <host> <database> > db.sql

    Parameter Breakdown

    • -p<password>: Password directly in command (no space between -p and password)
    • -e: Execute the following SQL command and exit
    • '<sql-command>;': SQL command enclosed in quotes

    Common MySQL Fuzzing Techniques

    View running processes:

    mysql -u <username> -p<password> -h <host> -e 'SHOW PROCESSLIST;'

    Tips for MySQL Fuzzing

    1. Always test with minimal privileges first - Start with limited user accounts
    2. Use information_schema - Rich source of metadata about database structure
    3. Check for default credentials - root/root, admin/admin, etc.
    4. Test different ports - MySQL default is 3306, but check other ports
    5. Look for configuration files - my.cnf often contains sensitive information
    6. Check for UDF (User Defined Functions) - Can lead to code execution

    Common Default Credentials

    • root / (blank)
    • root / root
    • admin / admin
    • mysql / mysql
    • test / test
